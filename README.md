# Python AD Audit

Projet personnel pour simuler et analyser des données Active Directory
avec Python/Pandas, dans le cadre d'un stage sécurité/infra bancaire.

## Objectif
Générer des données AD fictives (utilisateurs, groupes, connexions)
et construire des scripts d'audit (comptes inactifs, incohérences).

## Structure
- data/ : données brutes et traitées
- scripts/ : scripts Python par phase
- outputs/ : résultats exportés (CSV, graphiques)
